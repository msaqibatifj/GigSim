# AI_USAGE

- **Claude Code** wrote most of the code, tests and docs in this repo under my direction and review: the LangGraph graphs, MCP servers, RAG variants, FastAPI app, worker, eval runners and the web client.
- **Runtime models:** open-weight models on Groq (`openai/gpt-oss-20b` for small nodes, `openai/gpt-oss-120b` for Writer/Critic; second configuration `qwen/qwen3.8-27b`). Embeddings `BAAI/bge-small-en-v1.5` and reranker `Xenova/ms-marco-MiniLM-L-6-v2` (dev-size open models in both profiles).
- **Synthetic data** (personas, mock jobs and clients, dev-set labels, GigSim client behaviour) was generated by scripts and hand-edited; see DATA_CARD.
- **Verification:** every number in README and report comes from `evals/results/*.json`. LLM-judge scores are reported only next to agreement with my own labels.
- I must be able to explain and modify every part in the viva; AI authorship is not a substitute for that.
